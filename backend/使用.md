# 企业知识库后端 — 使用

## 环境

- JDK 21（`F:/Environment/jdk-21.0.12.1`）+ Maven 3.9.9
- MySQL 8.0（本机 3306，root/root）

## 构建

```bash
cd knowledge-base-backend-master
cmd /c "set JAVA_HOME=<local-path> set PATH=%JAVA_HOME%\bin;<local-path> mvn -DskipTests package"
```

## 启动（最小链路，此前实测成功）

```bash
# 网关 8080
java -jar kb-gateway/target/kb-gateway-1.0.0-SNAPSHOT.jar
# 认证 8081（密码 root 覆盖）
java -jar kb-user-auth/target/kb-user-auth-1.0.0-SNAPSHOT.jar --spring.datasource.password=root
# 文档 8082
java -jar kb-document/target/kb-document-1.0.0-SNAPSHOT.jar --spring.datasource.password=root
```

> 数据库初始化 SQL 见 `sql/`，Nacos 需可访问（远程 8848）。

## 验证

- 接口文档：http://127.0.0.1:8081/doc.html、/8082/doc.html
- 登录：`POST http://127.0.0.1:8080/api/auth/auth/login`（admin / 123456）

## 停止

```bash
netstat -ano | findstr :8080 ; netstat -ano | findstr :8081 ; netstat -ano | findstr :8082
taskkill /PID <pid> /T /F
```
