# 企业知识库系统后端（knowledge-base-backend）

> Spring Boot 3.2 + MyBatis Plus 多模块 · 位置：11-智能知识库系统

## 介绍

基于 **Spring Boot 3.x + MyBatis Plus** 的企业级知识库管理系统后端，采用 **Maven 多模块架构**，提供完整用户权限管理 + 文档管理能力。本机已完整运行验证（网关 8080 / 认证 8081 / 文档 8082），接入 MySQL + Nacos 服务发现。

## 解决什么问题

- 企业知识沉淀与检索的组织化
- 用户权限、文档管理、AI 问答的统一后端
