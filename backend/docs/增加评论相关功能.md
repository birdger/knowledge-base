# 增加评论相关功能

## 一、概述

文档评论功能是知识库系统增强用户互动的重要手段，通过评论系统，用户可以对文档进行讨论、提问和反馈。本文将详细介绍如何在kb-document服务中实现完整的文档评论功能。

### 1.1 功能定位

评论系统作为用户互动的核心功能，提供以下核心能力：

| 功能模块 | 说明 | 使用场景 |
|---------|------|---------|
| 评论创建 | 发表对文档的评论或回复其他评论 | 用户反馈、问题讨论 |
| 评论删除 | 删除自己的评论 | 撤回不当言论 |
| 点赞/取消点赞 | 对评论进行点赞表示认同 | 内容质量反馈 |
| 评论列表 | 分页查看文档的所有评论 | 评论浏览 |
| 评论回复 | 对评论进行二级回复 | 深度讨论 |
| 评论排序 | 支持按时间或点赞数排序 | 热门评论展示 |

### 1.2 评论系统设计要点

**层级结构设计：**
- 支持两级评论结构：根评论 + 子评论（回复）
- 最多支持两级，避免嵌套过深影响体验
- 通过`parentId`和`rootId`字段实现层级关联

**点赞系统设计：**
- 独立的点赞表`tb_like`支持多种目标类型
- 通过`targetType`区分文档点赞和评论点赞
- 防止重复点赞的唯一索引设计

**计数策略：**
- 评论表冗余存储`likeCount`和`replyCount`
- 通过数据库原子操作保证计数准确性
- 避免频繁查询关联表影响性能

### 1.3 数据模型

```
文档 (Document)
    ├── 根评论1 (Comment, parentId=0)
    │   ├── 回复1 (Comment, parentId=根评论1.id, rootId=根评论1.id)
    │   └── 回复2 (Comment, parentId=根评论1.id, rootId=根评论1.id)
    ├── 根评论2 (Comment, parentId=0)
    └── ...
```

点赞表设计：
```
tb_like
    ├── 文档点赞 (targetType=1)
    └── 评论点赞 (targetType=2)
```

## 二、数据库设计

### 2.1 评论表结构

```sql
-- 评论表
DROP TABLE IF EXISTS `tb_comment`;
CREATE TABLE `tb_comment` (
    `id` BIGINT(20) PRIMARY KEY COMMENT '评论ID（雪花ID）',
    `document_id` BIGINT(20) NOT NULL COMMENT '文档ID',
    `parent_id` BIGINT(20) COMMENT '父评论ID',
    `root_id` BIGINT(20) COMMENT '根评论ID',

    `content` TEXT NOT NULL COMMENT '评论内容',

    `commenter_id` BIGINT(20) NOT NULL COMMENT '评论人ID',
    `commenter_name` VARCHAR(50) COMMENT '评论人姓名',
    `commenter_avatar` VARCHAR(500) COMMENT '评论人头像',

    `reply_to_user_id` BIGINT(20) COMMENT '回复给谁（用户ID）',
    `reply_to_user_name` VARCHAR(50) COMMENT '回复给谁（用户姓名）',

    `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态：0-隐藏，1-正常',

    `like_count` INT DEFAULT 0 COMMENT '点赞数',
    `reply_count` INT DEFAULT 0 COMMENT '回复数',

    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    `deleted` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '删除标记',

    KEY `idx_document_id` (`document_id`),
    KEY `idx_parent_id` (`parent_id`),
    KEY `idx_root_id` (`root_id`),
    KEY `idx_commenter_id` (`commenter_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='评论表';
```

### 2.2 点赞表结构

```sql
-- 点赞表
DROP TABLE IF EXISTS `tb_like`;
CREATE TABLE `tb_like` (
    `id` BIGINT(20) PRIMARY KEY COMMENT '点赞ID',
    `target_id` BIGINT(20) NOT NULL COMMENT '目标ID（文档或评论）',
    `target_type` TINYINT NOT NULL COMMENT '目标类型：1-文档，2-评论',
    `user_id` BIGINT(20) NOT NULL COMMENT '用户ID',

    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',

    UNIQUE KEY `uk_target_user_type` (`target_id`, `user_id`, `target_type`),
    KEY `idx_target_id` (`target_id`),
    KEY `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='点赞表';
```

### 2.3 字段说明

**评论表 (tb_comment) 字段说明：**

| 字段 | 类型 | 说明 | 必填 | 默认值 |

| parent_id | BIGINT | 父评论ID（0表示根评论） | 否 | 0 |
| root_id | BIGINT | 根评论ID | 否 | - |
| content | TEXT | 评论内容 | 是 | - |
| commenter_id | BIGINT | 评论人ID | 是 | - |
| commenter_name | VARCHAR(50) | 评论人姓名（冗余） | 否 | - |
| commenter_avatar | VARCHAR(500) | 评论人头像（冗余） | 否 | - |
| reply_to_user_id | BIGINT | 回复给谁的用户ID | 否 | - |
| reply_to_user_name | VARCHAR(50) | 回复给谁的用户姓名（冗余） | 否 | - |

| 字段 | 类型 | 说明 | 必填 | 默认值 |
|------|------|------|------|--------|

### 2.4 索引设计

**评论表索引：**
- **主键索引**：`id` - 主键唯一标识
- **普通索引**：`idx_document_id` - 加速按文档查询评论
- **普通索引**：`idx_parent_id` - 加速查询子评论
- **普通索引**：`idx_root_id` - 加速查询评论树
- **普通索引**：`idx_commenter_id` - 加速按用户查询评论

**点赞表索引：**
- **主键索引**：`id` - 主键唯一标识
- **唯一索引**：`uk_target_user_type` - 防止重复点赞
- **普通索引**：`idx_target_id` - 加速按目标查询点赞
- **普通索引**：`idx_user_id` - 加速按用户查询点赞

- 冗余存储用户信息（姓名、头像）避免关联查询
- 冗余存储计数信息（点赞数、回复数）提升查询性能

@Slf4j
@Service
public class CommentServiceImpl extends ServiceImpl<CommentMapper, Comment> implements CommentService {

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long createComment(CommentCreateDTO dto) {

            jdbcTemplate.update(

        comment.setParentId(dto.getParentId() != null ? dto.getParentId() : 0L);
        comment.setRootId(rootId);
        comment.setContent(dto.getContent());
        comment.setCommenterId(userId);
        comment.setCommenterName(userName);
        comment.setCommenterAvatar(userAvatar);
        comment.setReplyToUserId(dto.getReplyToUserId());
        comment.setStatus(1);
        comment.setLikeCount(0);
        comment.setReplyCount(0);
        comment.setCreatedAt(LocalDateTime.now());
        comment.setUpdatedAt(LocalDateTime.now());
        comment.setDeleted(0);

        // 保存评论
        int count = commentMapper.insert(comment);
        if (count <= 0) {
            throw new BusinessException("创建评论失败");
        }

        // 更新文档的评论数
        jdbcTemplate.update(
                "UPDATE kb_document SET comment_count = comment_count + 1 WHERE id = ?",
                dto.getDocumentId()

        return comment.getId();

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Boolean deleteComment(Long commentId) {
        log.info("删除评论：commentId={}", commentId);

        if (commentId == null) {
            throw new BusinessException("评论ID不能为空");
        }

        // 检查评论是否存在
        Comment comment = commentMapper.selectById(commentId);
        if (comment == null) {
            throw new BusinessException("评论不存在");
        }

        // TODO: 检查权限，只有评论作者或管理员可以删除

        // 检查是否有子评论
        Long childCount = commentMapper.selectCount(
                new LambdaQueryWrapper<Comment>()
                        .eq(Comment::getParentId, commentId)
        );
        if (childCount > 0) {
            throw new BusinessException("该评论下有回复，不能删除");
        }

        // 删除评论
        int count = commentMapper.deleteById(commentId);

        // 更新父评论的回复数
        if (comment.getParentId() != null && comment.getParentId() > 0) {
            jdbcTemplate.update(
                    "UPDATE tb_comment SET reply_count = reply_count - 1 WHERE id = ?",
                    comment.getParentId()
            );
        }

        // 更新文档的评论数
        if (count > 0) {
            jdbcTemplate.update(
                    "UPDATE kb_document SET comment_count = comment_count - 1 WHERE id = ?",
                    comment.getDocumentId()
            );
        }

        return count > 0;
    }

        Comment comment = commentMapper.selectById(commentId);

        Long userId = 1L;

        if (count != null && count > 0) {

        }

                SnowflakeIdGenerator.getInstance().nextId(), commentId, userId
        );

        // 更新评论点赞数
        jdbcTemplate.update(

        Long userId = 1L;

    @Override
    public PageResult<CommentVO> pageDocumentComments(Long documentId, CommentQueryDTO dto) {
        // 构建查询条件 - 只查询根评论
        LambdaQueryWrapper<Comment> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(Comment::getDocumentId, documentId)
                .eq(Comment::getParentId, 0)
                .eq(Comment::getStatus, 1);

        // 排序
        if (StringUtils.hasText(dto.getSortBy())) {
            if ("like_count".equals(dto.getSortBy())) {
                wrapper.orderByDesc(Comment::getLikeCount);
            } else {
                boolean isAsc = "asc".equals(dto.getSortOrder());
                if (isAsc) {
                    wrapper.orderByAsc(Comment::getCreatedAt);
                } else {
                    wrapper.orderByDesc(Comment::getCreatedAt);
                }
            }
        } else {
            wrapper.orderByDesc(Comment::getCreatedAt);
        }

        // 分页查询
        Page<Comment> page = new Page<>(dto.getCurrent(), dto.getSize());
        IPage<Comment> commentPage = commentMapper.selectPage(page, wrapper);

        // 转换为VO并加载子评论
        IPage<CommentVO> voPage = commentPage.convert(comment -> {
            CommentVO vo = convertToVO(comment);
            // TODO: 设置是否已点赞
            vo.setIsLiked(false);
            // 加载子评论
            vo.setReplies(getCommentReplies(comment.getId()));
            return vo;
        });

        return PageResult.<CommentVO>builder()
                .records(voPage.getRecords())
                .total(voPage.getTotal())
                .current(voPage.getCurrent())
                .size(voPage.getSize())
                .build();
    }

    @Override
    public List<CommentVO> getCommentReplies(Long parentCommentId) {
        if (parentCommentId == null || parentCommentId <= 0) {
            return new ArrayList<>();
        }

        List<Comment> comments = commentMapper.selectList(
                new LambdaQueryWrapper<Comment>()
                        .eq(Comment::getParentId, parentCommentId)
                        .eq(Comment::getStatus, 1)
                        .orderByAsc(Comment::getCreatedAt)
        );

        return comments.stream()
                .map(comment -> {
                    CommentVO vo = convertToVO(comment);
                    // TODO: 设置是否已点赞
                    vo.setIsLiked(false);
                    return vo;
                })
                .collect(Collectors.toList());
    }

    /**
     * 转换为VO
     *
     * @param comment 评论实体
     * @return 评论VO
     */
    private CommentVO convertToVO(Comment comment) {
        return CommentVO.builder()
                .id(comment.getId())
                .documentId(comment.getDocumentId())
                .parentId(comment.getParentId())
                .rootId(comment.getRootId())
                .content(comment.getContent())
                .commenterId(comment.getCommenterId())
                .commenterName(comment.getCommenterName())
                .commenterAvatar(comment.getCommenterAvatar())
                .replyToUserId(comment.getReplyToUserId())
                .replyToUserName(comment.getReplyToUserName())
                .status(comment.getStatus())
                .likeCount(comment.getLikeCount() != null ? comment.getLikeCount() : 0)
                .replyCount(comment.getReplyCount() != null ? comment.getReplyCount() : 0)
                .createdAt(comment.getCreatedAt())
                .build();
    }
}

## 十、高级特性

### 10.1 评论树形结构处理

当前实现采用两层结构（根评论+子评论），通过以下方式实现：

1. **数据模型设计：**
   - `parentId=0`表示根评论
   - 子评论的`rootId`指向根评论ID

2. **查询逻辑：**
   - 先查询所有根评论
   - 再批量查询每个根评论的子评论
   - 在内存中组装成树形结构

3. **优势：**
   - 避免无限嵌套导致的性能问题
   - 前端展示更简洁
   - 查询效率高

### 10.2 计数器更新策略

为保证计数准确性，采用以下策略：

1. **数据库原子操作：**
   ```sql
   UPDATE tb_comment SET like_count = like_count + 1 WHERE id = ?
   ```

2. **事务保证一致性：**
   - 点赞记录插入和计数更新在同一事务
   - 失败时自动回滚

3. **避免并发问题：**
   - 使用数据库锁机制
   - 防止计数不准确

### 10.3 点赞防重复设计

1. **唯一索引约束：**
   ```sql
   UNIQUE KEY `uk_target_user_type` (`target_id`, `user_id`, `target_type`)
   ```

2. **应用层检查：**
   - 插入前先查询是否已存在
   - 抛出友好错误提示

### 10.4 内容安全过滤建议

生产环境建议增加：

1. **敏感词过滤：**
   - 集成内容安全检测服务
   - 过滤垃圾信息和广告

2. **评论审核：**
   - 新评论先进入待审核状态
   - 审核通过后对外展示

3. **频率限制：**
   - 限制用户评论频率
   - 防止刷屏攻击

### Q1: 如何防止刷赞？

- 验证码：频繁操作时要求验证
- 账号行为分析：识别异常账号行为
- 异常检测：监控点赞频率突增

### Q2: 评论支持编辑功能吗？

**A:** 当前不支持，如需支持：
1. 在评论表增加`updated_at`和`edit_count`字段
2. 添加编辑接口和权限校验
3. 记录编辑历史用于审计
4. 前端显示"已编辑"标识

4. 前端高亮显示@用户

### Q4: 子评论支持无限层级吗？

**A:** 当前只支持两级，原因：
- 避免嵌套过深影响性能
- 用户体验更好
- 大多数场景两级足够

如需支持多级：
1. 修改查询逻辑支持递归
2. 使用闭包表或物化路径模式
3. 考虑性能影响
