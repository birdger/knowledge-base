# 企业知识库后端 — 功能

## 核心功能（模块维度）

- [x] **kb-gateway**：统一网关（8080），路由 + 负载均衡（lb://）
- [x] **kb-user-auth**：用户认证（8081）：登录/权限/验证码
- [x] **kb-document**：文档服务（8082）：分类/CURD/上传
- [x] **kb-search**：文档检索
- [x] **kb-file**：文件服务（上传/预览）
- [x] **kb-ai**：AI 问答（RAG 式知识问答）
- [x] **kb-graph**：知识图谱
- [x] **kb-statistics**：统计报表
- [x] **kb-foundation**：基础能力（WebSocket）
- [x] **kb-common**：公共模块

## 认证与安全

- 登录接口：`POST /api/auth/auth/login`（实测 admin/123456 通过）
- JWT 鉴权：token 过期 7200s，Bearer 模式
- 验证码登录防爆破

## 服务发现与配置

- Nacos 服务注册与配置中心（远程）
- Knife4j 接口文档（/doc.html 实测 200）
