# 企业知识库前端 — 使用

## 环境

- Node（本机 `/c/nvm4w/nodejs`，v24）
- npm（国内镜像需 unset 代理 + --maxsockets=5）

## 安装

```bash
cd knowledge-base-frontend-master
npm install
```

## 开发运行（3002）

```bash
npm run dev
```

> 依赖后端网关 8080（代理 /api → 8080）。

## 构建

```bash
npm run build   # 输出 dist/
```

## 停止

```bash
netstat -ano | findstr :3002
taskkill /PID <pid> /T /F
```
