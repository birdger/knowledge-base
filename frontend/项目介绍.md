# 知识库前端门户（KB Frontend）

> 个人全栈实战项目系列 · 项目简介

## 一、项目简介
知识库前端门户是一个基于 React 18 构建的实战型项目，定位于「KB Frontend」。
项目覆盖从需求、架构到落地的完整链路，适合作为学习与企业级参考。

## 二、技术栈
- React 18
- Ant Design 5
- @ant-design/charts
- Vite
- STOMP / WebSocket
- Axios
- TypeScript

## 三、核心功能
- 知识库 Web 门户：文档浏览、搜索、协作、AI 问答
- 对接后端网关 8080，实时消息走 WebSocket

## 四、系统架构
Vite + React 单页应用，开发服务器端口 3002，API 反向代理到 http://localhost:8080。

## 五、模块 / 目录结构
- knowledge-base-frontend-master（前端）

## 六、默认访问地址
- **知识库门户**：http://localhost:3002/

## 七、数据存储
无（纯前端，数据来自后端知识库微服务）。

## 八、演示账号
